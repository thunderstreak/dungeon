# 地牢探险 - 开发任务计划

## 概述

本文档基于全部设计文档，将开发工作拆分为 **8个阶段、78个任务**，按依赖关系排序，支持渐进式开发。

**技术栈**: Phaser 3 + TypeScript + Vite + pnpm
**预计总工时**: 35~48天

---

完成 **阶段一~六** 即可获得最小可玩版本:

- 可启动游戏，进入主菜单
- 可在城镇中移动，与NPC交互（铁匠/商人/技能导师/转职导师/银行家/占卜师/炼金师/传送师）
- 可进入地牢，探索随机生成的地图
- 可与怪物实时战斗（普通怪+精英怪），使用技能和物品
- 可打开背包、装备界面、技能栏、快捷栏
- 可进行装备强化/修理/分解、炼金制作、装备鉴定
- 所有UI界面可见且可交互（含存档管理、深渊选择、死亡界面）
