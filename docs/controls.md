# 操作方式

---

## 1. 移动

- **右键点击地面**: 角色奔跑移动到目标位置，同时取消当前的攻击行为
- **移动中再次右键**: 更新奔跑目标
- **右键按住拖动**: 持续奔跑（朝拖动方向移动）

---

## 2. 左键操作

左键根据鼠标下方的目标自动执行不同操作：

| 目标 | 操作 |
|------|------|
| 地面 | 取消当前选中目标 |
| NPC | 触发对话/交互 |
| 怪物 | 选中怪物，自动奔跑到怪物面前进行攻击 |

- **鼠标悬停怪物**: 高亮显示目标怪物（显示血条、名称）
- **左键点击怪物**: 选中怪物并自动奔跑到怪物面前进行攻击
- 攻击范围内直接攻击，范围外自动奔跑接近后攻击
- **左键点击地面**: 取消当前目标选中
- **右键点击地面**: 取消攻击行为，改为奔跑移动

---

## 3. 技能释放

- **快捷键 1~8**: 释放对应槽位的技能
- **指向性技能**: 鼠标悬停在目标上，按快捷键释放
- **范围技能**: 以鼠标位置为技能中心释放
- **自身增益技能**: 直接按快捷键对自身释放
- **无目标时**: 技能朝角色面朝方向释放

---

## 4. 物品使用

- **快捷键 1~8**: 使用物品快捷栏对应槽位的物品
- 使用后自动从背包消耗

---

## 5. 界面操作

| 按键 | 功能 |
|------|------|
| `I` | 打开/关闭背包界面 |
| `E` | 打开/关闭装备界面 |
| `C` | 打开/关闭角色属性面板 |
| `M` | 打开/关闭小地图（地牢内） |
| `ESC` | 关闭当前界面 / 打开系统菜单 |
| `Tab` | 切换背包分类标签页 |

---

## 6. NPC交互

- 对话框弹出后，左键点击选项进行选择
- 商店/铁匠等界面通过对话触发打开

---

## 7. 快捷操作

| 按键 | 功能 |
|------|------|
| `Space` | 拾取地面物品 |
| `F` | 与最近的可交互对象互动（NPC/宝箱/门） |
| `R` | 坐下/休息（缓慢恢复HP/MP） |
