# 强化材料详细设定

## 1. 材料概述

强化材料用于装备强化和修理。通过分解装备、怪物掉落、宝箱获取。

---

## 2. 基础强化材料

| 材料名称 | 品质 | 获取方式 | 用途 |
|---------|------|---------|------|
| 普通矿石 | 白色 | 分解白色装备、怪物掉落 | +1~+5强化 |
| 精铁矿 | 蓝色 | 分解蓝色装备、怪物掉落 | +1~+10强化 |
| 秘银矿 | 紫色 | 分解紫色装备、怪物掉落 | +6~+15强化 |
| 精金矿 | 粉色 | 分解粉色装备、Boss掉落 | +11~+20强化 |
| 深渊结晶 | 橙色 | 分解橙色装备、深渊Boss | +16~+20强化 |

---

## 3. 辅助强化材料

| 材料名称 | 品质 | 效果 | 获取方式 |
|---------|------|------|---------|
| 强化保护券 | 紫色 | 强化失败不降级 (+11以上) | Boss掉落、商店 |
| 幸运符 | 粉色 | 强化成功率+15% | 深渊模式、稀有掉落 |
| 完美强化石 | 橙色 | 强化必定成功 (限+15以下) | 深渊Boss |
| 耐久修复卷 | 白色 | 修复装备50%耐久 | 商店、怪物掉落 |
| 完全修复卷 | 蓝色 | 修复装备100%耐久 | 商店、宝箱 |

---

## 4. 装备分解

**分解规则**:
| 装备品质 | 获得材料 | 数量 |
|---------|---------|------|
| 白色 | 普通矿石 | 1个 |
| 蓝色 | 精铁矿 | 1~2个 |
| 紫色 | 秘银矿 | 1~2个 |
| 粉色 | 精金矿 | 1个 |
| 橙色 | 深渊结晶 | 1个 |

**额外分解奖励**:
- 强化+10以上装备: 额外获得1个对应品质材料
- 套装装备: 额外获得1个对应品质材料
- 分解有几率获得稀有材料 (白色5%、蓝色10%、紫色15%、粉色20%)

## 6. 材料获取途径汇总

| 途径 | 可获取材料 |
|------|-----------|
| 普通怪物掉落 | 普通矿石、精铁矿 (低概率) |
| 精英怪物掉落 | 普通矿石、精铁矿、秘银矿 (低概率) |
| Boss掉落 | 精铁矿、秘银矿、精金矿、深渊结晶 |
| 深渊模式 | 全部材料，高级材料概率提升 |
| 宝箱 | 随机材料 |
| 商店购买 | 普通矿石、精铁矿 |
| 分解装备 | 对应品质材料 |
| 炼金师制作 | 部分高级材料可合成 |
