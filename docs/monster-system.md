# 怪物系统详细设定

## 1. 怪物概述

### 1.1 怪物设计原则

- 每层有3~5种普通怪物
- 难度随层数递增 (1.25~2倍/层)
- 怪物类型: 近战/远程/法术/辅助
- 怪物等级与层数挂钩

### 1.2 怪物类型

| 类型 | 说明 | 行为模式 |
|------|------|---------|
| 近战 | 近距离攻击 | 接近玩家后近身攻击 |
| 远程 | 远距离攻击 | 保持距离，远程投射攻击 |
| 法术 | 魔法攻击 | 保持距离，释放魔法技能 |
| 辅助 | 增益/治疗 | 为其他怪物提供增益 |

### 1.3 怪物分类

| 分类 | 说明 | 特点 |
|------|------|------|
| 普通怪 | 基础怪物 | 属性一般，掉落普通 |
| 精英怪 | 强化怪物 | 属性×1.5，必定掉落蓝色以上装备 |
| Boss | 层守关Boss | 属性×10，专属技能和掉落 |

## 2. 怪物属性系统

### 2.1 基础属性

| 属性 | 说明 | 计算方式 |
|------|------|---------|
| HP | 生命值 | 基础值 × 层数倍率 |
| MP | 魔法值 | 基础值 × 层数倍率 |
| 物理攻击 | 物理伤害 | 基础值 × 层数倍率 |
| 魔法攻击 | 魔法伤害 | 基础值 × 层数倍率 |
| 物理防御 | 减免物理伤害 | 基础值 × 层数倍率 |
| 魔法防御 | 减免魔法伤害 | 基础值 × 层数倍率 |
| 攻击速度 | 攻击频率 | 基础值 (100%) |
| 移动速度 | 移动快慢 | 基础值 (100%) |
| 暴击率 | 暴击概率 | 基础值 |
| 暴击伤害 | 暴击倍率 | 基础值 (150%) |

### 2.3 精英怪加成

- HP: ×1.5
- 攻击: ×1.5
- 防御: ×1.5
- 经验: ×2
- 金币: ×3
- 掉落: 必定掉落1件蓝色以上装备

### 2.4 深渊模式加成

- HP: ×2.0~2.5
- 攻击: ×2.0~2.5
- 防御: ×2.0~2.5
- 经验: ×2
- 金币: ×2
- 粉色/橙色掉落率: ×3

## 3. 仇恨系统

### 3.1 仇恨值机制

**仇恨值来源**:
| 行为 | 仇恨值 |
|------|--------|
| 造成伤害 | +100% 伤害值 |
| 治疗队友 | +50% 治疗量 |
| 使用嘲讽技能 | +500 固定值 |
| 进入警戒范围 | +100 固定值 |

**仇恨衰减**:
- 每秒衰减 5% 当前仇恨值
- 脱离战斗后仇恨值清零

### 3.2 仇恨目标选择

```
1. 计算所有目标的当前仇恨值
2. 选择仇恨值最高的目标
3. 如果仇恨值差距 < 10%，随机选择
4. 如果目标死亡，切换到下一高仇恨目标
```

### 3.3 警戒范围

| 怪物类型 | 警戒范围 | 说明 |
|---------|---------|------|
| 近战 | 3格 | 发现玩家后接近 |
| 远程 | 5格 | 保持距离攻击 |
| 法术 | 6格 | 保持距离施法 |
| 辅助 | 4格 | 跟随队友 |
