# 药水系统详细设定

## 1. 药水概述

- **使用方式**: 快捷栏使用，有冷却时间
- **获取方式**: 怪物掉落、宝箱、商店购买、炼金师制作
- **携带上限**: 每种药水最多携带20瓶
- **快捷栏**: 可放入8个快捷栏位 (快捷键1~8)

## 5. 炼金师制作

**制作消耗**:
- 基础材料: 草药、矿石、魔法精华
- 制作费用: 材料费 + 加工费

**制作配方示例**:

| 药水 | 材料 | 制作费 |
|------|------|--------|
| 中型生命药水 | 小型生命药水×3 + 草药×2 | 10金币 |
| 力量药水II | 力量药水×3 + 魔法精华×1 | 20金币 |
| 狂暴药水 | 力量药水II×2 + 矿石×3 + 魔法精华×2 | 50金币 |
| 复活药水 | 特大生命药水×2 + 魔法精华×5 + 稀有矿石×1 | 200金币 |
