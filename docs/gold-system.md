# 金币系统详细设定

## 1. 金币概述

- **货币名称**: 金币
- **用途**: 购买物品、修理装备、强化装备、学习技能等
- **存储方式**: 角色携带，无上限
- **获取方式**: 出售物品、击败怪物、任务奖励

## 4. 金币经济平衡

### 4.1 每日收入预估

**普通玩家 (每天1小时)**:
- 击杀怪物: ~50只 × 30金币 = 1500金币
- 出售装备: ~500金币
- 总计: ~2000金币/天

**中等玩家 (每天2小时)**:
- 击杀怪物: ~100只 × 80金币 = 8000金币
- 出售装备: ~2000金币
- Boss掉落: ~500金币
- 总计: ~10000金币/天

**重度玩家 (每天4小时)**:
- 击杀怪物: ~200只 × 150金币 = 30000金币
- 出售装备: ~5000金币
- Boss掉落: ~2000金币
- 深渊模式: ~3000金币
- 总计: ~40000金币/天

### 4.2 每日支出预估

**新手阶段 (1~20级)**:
- 药水购买: ~200金币
- 装备修理: ~100金币
- 强化费用: ~500金币
- 总计: ~800金币/天

**中期阶段 (21~40级)**:
- 药水购买: ~500金币
- 装备修理: ~300金币
- 强化费用: ~3000金币
- 总计: ~3800金币/天

**后期阶段 (41~60级)**:
- 药水购买: ~1000金币
- 装备修理: ~500金币
- 强化费用: ~15000金币
- 总计: ~16500金币/天

### 4.3 金币沉淀

**主要金币消耗点**:
- 装备强化 (+16~+20): 大量金币消耗
- 高级药水购买: 持续消耗
- 装备修理: 持续消耗
- 仓库扩展: 一次性消耗

**金币回收机制**:
- 死亡惩罚: 损失10%当前金币
- 强化失败: 金币不退还
- 商店购买: 金币流出
