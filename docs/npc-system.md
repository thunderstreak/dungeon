# NPC系统详细设定

## 1. NPC概述

- **位置**: 城镇各区域
- **交互方式**: 靠近NPC后按交互键/点击打开对话
- **功能**: 提供各种服务（强化、买卖、学习、传送等）
- **外观**: 每个NPC有独特的像素外观和站立位置

### 3.2 商人 (Merchant)

**位置**: 商业区

**功能**:
- 购买物品
- 出售物品

**商店库存** (根据玩家等级解锁):

| 物品 | 价格 | 解锁等级 | 每日限购 |
|------|------|---------|---------|
| 小型生命药水 | 10金币 | 1 | 无 |
| 中型生命药水 | 30金币 | 10 | 无 |
| 大型生命药水 | 80金币 | 20 | 无 |
| 小型魔力药水 | 15金币 | 1 | 无 |
| 中型魔力药水 | 45金币 | 10 | 无 |
| 大型魔力药水 | 120金币 | 20 | 无 |
| 解毒药水 | 5金币 | 1 | 无 |
| 净化药水 | 30金币 | 15 | 无 |
| 传送药水 | 50金币 | 10 | 5瓶/天 |
| 耐久修复卷 | 100金币 | 1 | 10张/天 |
| 完全修复卷 | 300金币 | 20 | 5张/天 |
| 普通矿石 | 50金币 | 1 | 20个/天 |
| 精铁矿 | 200金币 | 15 | 10个/天 |

## 5. NPC交互系统

### 5.1 对话系统

**对话触发条件**:
- 靠近NPC后按交互键
- 点击NPC

**对话类型**:
- 普通对话: 介绍功能
- 功能对话: 打开功能界面
- 任务对话: 发布/完成任务（预留）

### 5.2 商店刷新

**每日刷新时间**: 00:00

**刷新内容**:
- 商店库存重置
- 每日限购重置
- 随机出现稀有物品（5%几率）

### 5.3 NPC好感度（预留）

**好感度系统**:
- 与NPC交互增加好感度
- 好感度达到一定等级解锁特殊功能/折扣
- 好感度等级: 陌生人→熟人→朋友→挚友
